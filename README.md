# School Soccer mini boy

Futebol arcade no navegador. Esta pasta já está pronta para abrir: `index.html`, `game.js` e `styles.css`.

## Modo local

No menu, entre em **Local**. Cada teclado ou controle USB/Bluetooth vira um jogador.

- Clássico 1v1: um contra um
- 2 juntos: dois no mesmo time contra a CPU
- 2v2: dois contra dois

Aperte um botão em cada controle para o navegador reconhecer. USB e Bluetooth aparecem na mesma lista.

Controle: analógico esquerdo move, A passa, B chuta, X cruza, Y passe profundo, LB corre, RB troca, LT carrinho, RT drible.
